# Agora Comprehensive World Evaluation

Publication package for the August 26, 2026 comprehensive evaluation of generated-world quality and performance.

## Contents

- `agora_comprehensive_world_evaluation_20260826.pdf`: final report
- `report.tex`: LaTeX source
- `make_figures.py`: deterministic vector-figure generator
- `figures/`: PDF and PNG versions of all seven figures
- `data/`: comprehensive, dual-judge, and objective source data
- `build.sh`: reproducible local build

## Build

```bash
./build.sh
```

The report combines 40% blind dual-judge world quality, 35% objective generation, and 25% objective runtime performance.
