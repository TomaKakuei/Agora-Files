\noindent\textbf{Abstract.}
A generated social world needs a connection between its description and
what its inhabitants can actually change. We present \agora, a mechanism
for compiling a short premise into a persistent rendered environment for
human--AI interaction. A shared world representation binds roles, places,
possessions, knowledge, and visual assets to stable entity identities;
dependency-directed validation and repair keep these components consistent.
A generated action repertoire makes situated activities discoverable, while
an open-proposal channel expresses intentions beyond that repertoire. The
World Coordinator checks structured effects against the generated state
before committing changes that become available to subsequent actors.
The central contribution is this coupling of world construction, situated
action, and persistent consequences. We examine its operation through
construction checks, execution traces, and an existing visual study with
ten eligible respondents. Validators detect all 58 seeded faults; five
local repairs preserve unaffected generation stages. Five generated worlds
exercise both action pathways. Longer scripted traces expose committed
inventory and location changes, rejected effects, and the distinction between
an executed action and useful task progress. Supplementary planner-input and
action-space ablations document implementation behavior with replayable
records. These studies establish the implemented connection from generated
world structure to checkable state transitions; human collaboration and
behavioral fidelity remain separate evaluation questions.
