# Agora 完整比较问卷 · 2026-09-19 v2

本包包含真实世界材料、可离线填写的双语问卷、打印版、分配表和分析脚本。目前没有收集任何真实受试者答卷。

## 发给参与者什么

只发送 `public/START_SURVEY.html`（或 `participants_only.zip`），并从 `researcher_only/assignment_roster.csv` 分配一个唯一编号。电脑浏览器直接打开即可，不需要安装或联网。参与者完成四组比较后下载 JSON，再按你的收集方式交回。文件不会自动上传答卷。

**不要把本研究者完整包或 researcher_only 目录发给参与者**：里面有模型和方法的解盲表。问卷正文不展示模型名、方法名、评分、完成率、token 或作者分析。原始世界文本仍可能留下文风线索，因此是身份标签盲化，不保证受试者无法推测来源。

先发 P001–P008 做试填。正式编号 S001–S082 分配给不同参与者，不重复使用。82 是用于平衡材料的一个设计周期，不是功效分析得出的最低人数。若预算不足，报告实际覆盖；不要把仅几人的每对比较包装为稳定排名。若需扩大，先生成独立的新编号和同样平衡的分配表，再开始追加招募。

## 两类对决

1. **模型对决**：使用 8 个现有日志模型在同一套 3 条一句话提示上的生成记录；7 个模型有成功世界，共 17 份，组成 41 个同提示模型对。GPT-5.6 Luna 的 3 次均未生成成功，没有可评分成品，列入生成失败表，不伪造样本或自动算人工偏好败场。Terra 和 Gemini 3.5 Flash Lite 仅在第一条提示有成功成品，因此它们的偏好结果只适用于该提示。
2. **Agora 架构对决**：10 个共同生成要求，每个取预先固定的第 1 次输出，完整 compositional Agora 对 single-pass baseline，共 20 份、10 对。脚本逐项验证两种方法的原始 request 完全相同；共同编译器一致。原始要求包含较详细的 brief，不能称为严格一句话测试。即使最终合同检查失败，只要存在生成文本也照常展示该文本，并另报客观失败状态；不要在人工偏好中悄悄删除差的输出。

模型记录中的模型名称按日志原样保留；不把这些名称视为永远不变的提供商快照。跨模型比较是相同流水线下的现有输出比较。架构比较的总 token 预算并不相等，所以只能解释为现有系统配置的差异，不能隔离相同算力下分解架构的因果收益。

## 为什么不拿图片混进对决

单次生成基线没有与 Agora 配套的相同渲染条件图像。为了保持共同可观测范围，本版比较文字世界设计：设定、规则、活动、人物、地点、物件、动作和进入方式。所有材料由脚本按同样字段、原始顺序、数量和词数上限直接摘录，不由评审挑选最佳例子或为某一方润色。截断用 `[…]` 明示。

本包没有删掉图像质量的科学意义，而是把它留给未来有匹配图像的独立比较。旧问卷五个展示世界的视觉打分仍只能作为个案描述，不能与本次偏好票混算。

## 语言、时长和招募

界面和所有问题可切换中文／英文，证据保留生成时的英文原文，因此招募能独立阅读英文的成年人。不要临时只翻译其中一方。若需要纯中文参与者版本，应先统一翻译全部冻结材料，双人检查语义对应，并作为独立语言条件重新试填。

每人 4 场（2 场模型 + 2 场架构），每场 6 项判断和可选评论。每份证据约 217–476 个英文词。20–30 分钟是试填前估计，需要用 P001–P008 的真实完成情况更新。问卷没有奖励特定选择，没有默认答案，允许“相当”和“无法判断”。

分发前由你确定并向参与者说明研究联系人、答卷接收方式、保存期限以及是否有报酬；遵循你所在机构适用的人类研究流程。本包不声称已有伦理审批。建议不要在邀请中透露你期待哪方获胜。

## 交回后的分析

将正式收到的 JSON 放到一个新文件夹，然后运行：

```bash
python analyze_responses.py /path/to/returned_json --output /path/to/results
```

脚本拒绝重复编号、错误版本、分配不匹配和缺失评分；试填和已接触系统的参与者不进入预定主要分析。所有排除会留记录，不能因为评分低、选择相当或填得快而临时排除。主要分析以“总体世界设计”偏好为终点；五个维度用于诊断。主观偏好不得填进论文直到数据真实收集、清理和分析完成。

结果包含逐提示的偏好分布、同一模型对的提示等权平均、按参与者重采样的区间，以及缺失覆盖标记。区间只反映固定材料上的参与者差异，不代表新提示、新随机种子或整个模型能力。未覆盖完计划提示时不得报告完整比较结论。多项探索性比较不产生显著性星号或总 Elo 排名。

`coded_responses_PRIVATE.csv` 包含评论，只供研究者处理；不要直接公开。引用评论前还须检查参与者的单独引用同意并去除身份信息。

## 文件和复现

- `public/START_SURVEY.html`：唯一需要分发的互动问卷，含全部 37 份真实成品摘录。
- `questionnaire_master_zh.md`：可复制到问卷平台的完整题目和跳转规则。
- `questionnaire_example_P001.pdf`：包含 4 场真实材料的试填打印版，仅供编号 P001。
- `research_protocol.md`：招募、终点、样本选择、盲化和分析约定。
- `researcher_only/`：原始材料、哈希、盲化映射、生成失败记录和编号表。
- `build_study.py` / `survey_template.html`：问卷生成源文件。
- `analyze_responses.py`：答卷验证和描述性分析。
- `validate_study.py`：材料、随机化、盲化和人工构造测试数据的处理验证。

分析验证只使用明确标记的合成测试答卷，放在临时目录；不会作为研究结果发布。

方法参考：[Howcroft et al., 2020](https://aclanthology.org/2020.inlg-1.23/) 强调评价构念和报告透明性；[Chatbot Arena, 2024](https://arxiv.org/abs/2403.04132) 提供匿名成对偏好评价的相关方法背景。这里是小规模固定成品研究，不复用其排行榜有效性主张。
